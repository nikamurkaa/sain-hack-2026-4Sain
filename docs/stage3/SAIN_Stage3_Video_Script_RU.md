# SAIN Smart Room — сценарий честной live AI видеодемонстрации (5–8 минут)

**Релизный статус:** СЦЕНАРИЙ ПОДГОТОВЛЕН; реальная запись и полное сквозное voice acceptance **НЕ ПОДТВЕРЖДЕНЫ**.
**Ключевое пояснение на экране:** «AI/NLU/STT/TTS — внешний настоящий провайдер при действующем ключе; все устройства — локальный программный симулятор. Это не реальный гостиничный номер».

## До записи (не показывать ключи)
1. Убедиться, что разрешённый `LLM_API_KEY` действителен. Согласно README организаторов, исходный ключ прекращает действовать **23 ноября 2026, 12:00 МСК**; после этого для настоящей демонстрации нужен новый авторизованный доступ. Не обходить истечение срока.
2. Распаковать **SAIN-Smart-Room-Live-AI-Windows.zip** целиком. Запустить `CHECK_ENV.cmd` и `START.cmd` → режим **3 LIVE AI**. Ключ вводить только в скрытом консольном запросе или в переменных окружения оператора, никогда в браузере. `LLM_MODEL` должен соответствовать разрешённому значению.
3. В локальном CMD создать отдельный гостевой токен: `.venv\Scripts\python.exe -m scripts.client_access dev --stay stay_test`; открыть `http://127.0.0.1:4173`. Гостевой токен вводить только до начала записи, не показывать его в видео.
4. Проверить шильдик **LIVE AI · локальный симулятор** и раздел **Live AI · реальные обращения**. Отключить уведомления Windows, не открывать `.env`, `llm.key`, исходный командный архив, HTTP Authorization headers или консоль с секретами. Записывать окно приложения.
5. Снять исходный полный снимок состояния: `light` (brightness, color temperature), `climate` (temperature_c), `sound` (track, volume, timer), `curtains` (position), `alarm` (at, mode, window), `dnd` (enabled). Ожидать изменения только явно перечисленных полей. Исходные численные значения НЕ предполагаются.

## Ошибки и честность
- **402**: бюджет провайдера исчерпан — показать текст ошибки; не переключать незаметно в FakeLLM.
- **413**: аудио свыше 5 МБ — повторить запись меньшего размера.
- **429**: частотный лимит — ждать разрешённого интервала; не запускать ретраи пачкой.
- **401/403**: доступ истёк/запрещён — прекратить live-заявления; разрешается только отдельно обозначенная offline репетиция.
- **Timeout / unknown POST**: не повторять команду автоматически; только GET сверка состояния с серверным журналом, иначе блокировка дальнейших действий.
- **Запрет микрофона / отмена**: команду нельзя отправлять; показать исправление или текстовый путь.
- Не записывать личные токены, datasets, ключи, URL с закрытыми кодами, HTTP Authorization headers.
- **Не использовать запись прошлой сессии** как подтверждение текущего live acceptance.

## Финальная фраза на записи
«В этом прототипе модель понимает русский язык через внешний AI-провайдер, распознаёт аудио и озвучивает подтверждённые ответы при действующем доступе. Состояние шести устройств подтверждается **локальным программным симулятором**, а не реальными гостиничными системами».
