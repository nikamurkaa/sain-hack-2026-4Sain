# SAIN Smart Room · браузерный клиент

Клиент на React и TypeScript работает в браузере компьютера жюри. Браузер обращается к локальному HTTP-серверу, а тот пересылает клиентские запросы бэкенду команды. Профиль, ID проживания, расписание, каталог и подтверждённое состояние приходят с сервера. Имя и номер комнаты не входят в обязательный контракт. Интерфейс использует идентификатор проживания. Закрытие вкладки очищает токен.

## Запуск готовой сборки на компьютере жюри

Нужен Python 3.11 или новее. В архиве рядом с serve.py должна лежать папка dist. Из распакованной папки запустить:

```console
python serve.py --mode stand
```

Открыть **http://127.0.0.1:4173**. Локальный сервер доступен только на компьютере организаторов. Адрес стенда зафиксирован в serve.py. Кнопка микрофона требует разрешения пользователя. Временный клиентский токен вводится в поле подключения. Публичный компьютер не получает командный ключ. После показа выбрать «Меню → Сменить сеанс», чтобы отозвать текущий клиентский токен. Закрытие вкладки само по себе не отзывает серверный доступ.

### Выдача доступа оператором команды

На доверенном компьютере с зависимостями бэкенда открыть терминал в корне репозитория. Команды ниже предназначены для согласованной живой защиты. Для проверки разработки использовать раздел «Автономная репетиция». Командный ключ берётся из окружения или вводится скрыто в терминале. Единственный вывод успешной команды — временный токен для поля подключения. Не записывать терминал в трансляцию.

```console
python -m scripts.client_access final --origin https://team25.hack.be-healthy.tech
python -m scripts.client_access dev --origin https://team25.hack.be-healthy.tech --stay ID_РЕАЛЬНОГО_DEV_ПРОЖИВАНИЯ
```

Первая команда требует подготовленного финального профиля на стенде. Вторая создаёт отдельный dev-прогон и расходует ресурсы организаторов. Если нужен другой официальный код dev-набора, передайте его через --dataset. Используйте record_id именно этого набора. Время жизни final-токена — 30 минут. Срок dev ограничен официальным прогоном, максимум 45 минут с момента создания. При смене гостя в меню завершите старый сеанс и подключите выданный для нового гостя токен.

## Автономная репетиция

Из корня репозитория создать окружение Python 3.11 и установить зависимости. Команды ниже рассчитаны на активированное окружение.

```console
python -m pip install -r requirements-dev.txt
python -m scripts.rehearse_client
```

Оставить этот процесс открытым. Он слушает только 127.0.0.1:8765, запускает настоящий FastAPI и подставляет httpx.MockTransport, локальный симулятор и модель с заранее заданными ответами. Запись с микрофона настоящая, текст распознавания в репетиции фиксирован. В новом терминале из корня получить токен для выбранного режима:

```console
python -m scripts.client_access final
python -m scripts.client_access dev --stay stay_test
```

В отдельном терминале из frontend запустить готовый dist командой **python serve.py --mode rehearsal**. В интерфейсе появляется подпись «Репетиция». Параметр --port позволяет выбрать другой локальный порт. Тестовый API недоступен через публичный стенд.

### Сборка из исходников и тесты

Node.js 24, npm, активное окружение Python с requirements-dev.txt. В папке frontend:

```console
npm ci
npm run build
npm test
npx playwright install --with-deps chromium firefox
npm run e2e
```

Для прогона Firefox задать переменную SAIN_BROWSER=firefox. Для снимков всех состояний задать SAIN_SCREENSHOTS с каталогом вывода. Playwright сам поднимает локальные серверы на свободных портах 4173 и 8765. Остановить ручную репетицию перед E2E. Для работы над стилями доступен npm run dev; SAIN_API_ORIGIN задаёт адрес проксирования локального Vite. Внешние запросы к организаторам для тестов не нужны.

## Сценарий защиты

1. Открыть final. Выбрать «Профиль гостя», показать его ID, доступные предпочтения и источники. Открыть через меню «Заселение», нажать «Заселиться», показать время и шаги персонального плана.
2. Нажать «В номер». Показать последнее подтверждение и его время либо сообщение о недоступности живого чтения. Открыть «Виртуальное время» и выбрать доступный период. Часы диалога сохраняются.
3. Озвучить ограничение закрытого оценочного прогона. Выбрать «Меню → Сменить сеанс», подключить отдельный dev-токен. Показать подпись режима и идентификатор dev-проживания.
4. Открыть диалог и запомнить температуру. Нажать «Сделай попрохладнее». После ответа сравнить значение с прежним. Ввести «Ещё немного». Попросить «Поставь 35 градусов» и показать отказ и сохранённое состояние.
5. Нажать микрофон, произнести просьбу, завершить запись. Проверить текст, затем подтвердить отправку. При отказе в доступе к микрофону выбрать «Отменить» и использовать клавиатуру.
6. При потере ответа использовать «Повторить». Клиент передаст исходные идентификатор и тело. При истечении доступа запросить новый токен у оператора. Финальный профиль и dev-гость разделены.
