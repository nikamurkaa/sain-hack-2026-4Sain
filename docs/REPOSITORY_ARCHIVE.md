Дата консолидации: 22 ноября 2026 года. Исходный проект разработан в рамках SAIN × Школа 21, кейс №2. Это не официальный продукт SAIN и не заявка на участие в очном финале.

## Как сохранили историю

Актуальная версия backend и frontend объединена в основную ветку main штатным merge-коммитом PR #13, без squash и force-push. Исходные альтернативные и экспериментальные ветки были изучены перед закрытием: их единственный недостающий полезный файл, независимый тест tests/test_final_score_gate.py из PR #12, перенесён до merge.

Перед удалением старых веток создан полный Git bundle, проверенный по SHA-256 и git bundle verify. Он содержит сохранённые Git-объекты и первоначальные ссылки веток. Резервная копия не хранится внутри исходного Git-репозитория, чтобы не дублировать историю и не засорять main.

- GitHub Actions: https://github.com/nikamurkaa/sain-hack-2026-4Sain/actions/runs/45014683225
- Backup artifact: sain-all-branches-git-rescue, ID 14751282967
- SHA-256 внутреннего Git bundle: 10d99fc69733bb2795deeed8f5a92cfb0977d8f64941c58781fc2940f26ef082
- Проверка исторических blob-объектов по сигнатурам секретов: 371 inspected, 0 findings (не абсолютная гарантия безопасности).

Для просмотра резервной истории: скачать artifact, извлечь bundle и выполнить git bundle verify SAIN-Smart-Room-All-Branches.bundle; затем git clone SAIN-Smart-Room-All-Branches.bundle restored-repo. Исторические origin refs доступны внутри Git bundle, но старые ветки не поддерживаются.

## Что оставлено в main

Python/FastAPI, 19 намерений и R1–R8, управление шестью устройствами, сценарии и виртуальное время, React/TypeScript/Figma-ресурсы, автономный FakeLLM/MockSimulator, клиентский голосовой UI, API и UI регрессия, проверяемый Windows ZIP.

Архивная метка: v1.0.0-hackathon (указывает на окончательный main после консолидации). CI для main выполняет Python/React-тесты; никаких автоматических деплоев на хакатонный стенд нет.

Ограничения: Windows на физической машине и живые Bifrost/STT не подтверждены автономными CI. Официальный закрытый final read-only. Не публикуйте исторические токены и не считайте макеты или ассеты лицензией на использование бренда SAIN.
