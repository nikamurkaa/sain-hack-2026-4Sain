# Приёмка SAIN Smart Room на Windows

Этот кандидат запускается на Windows с Python 3.11+; Node.js и npm для готовой сборки не нужны. В ZIP должны быть `frontend/dist`, `frontend/serve.py`, `scripts/rehearse_client.py`, исходники Python и `START.cmd`.

1. Распакуйте ZIP полностью, запустите `CHECK_ENV.cmd`, проверьте Python 3.11+ (`py -0p`, `python --version`). Если отсутствует — установите с https://www.python.org/downloads/windows/ и перезапустите терминал.
2. `START.cmd` предлагает **REHEARSAL** (без официального API) и **STAND** (с официальным API). В репетиции при первом запуске может потребоваться установить Python-зависимости через интернет.
3. Для репетиции получите тестовый токен в CMD из распакованной папки: `.venv\\Scripts\\python.exe -m scripts.client_access dev --stay stay_test`. Вставьте только эту строку в браузер `http://127.0.0.1:4173`. Финальный тестовый гость: `.venv\\Scripts\\python.exe -m scripts.client_access final` (только просмотр).
4. Для STAND нужен **короткоживущий клиентский токен**, выданный оператором команды через разрешённый `scripts/client_access.py`. Командный ключ не вводить в браузер, в историю и в видео!
5. Пройдите: заселение → план вечер/ночь/утро → шесть устройств → «Сделай попрохладнее» → «Ещё немного» → «Ещё немного» → «Поставь 35 градусов» (отказ) → ручная настройка → профиль → виртуальное время.
6. Chrome: F12 → Ctrl+Shift+M → Responsive 375×812; дополнительные 320×568, 360×800, 390×844, 430×932. Desktop проверить 1440×900 и 1920×1080, фактическое окно считать через `innerWidth`/`innerHeight`, масштаб Ctrl+0.
7. Ошибка: Win+Shift+S для скриншота, F12 → Console/Network для журнала; убрать токены перед пересылкой. Для остановки запустите `STOP.cmd`. Для сброса локального состояния `RESET_TEST_STATE.cmd` и затем создайте новый репетиционный токен.

**Windows запуск в браузере должен быть проверен владельцем отдельно.** Никакие Linux/GitHub CI проверки сами по себе этого не доказывают. Подробнее — полная инструкция в Windows ZIP.
