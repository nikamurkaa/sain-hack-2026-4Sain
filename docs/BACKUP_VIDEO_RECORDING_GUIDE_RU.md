# Резервное видео SAIN Smart Room: съёмка 3–4 минуты

Сначала пройти сценарий без записи. В режиме REHEARSAL обязательно постоянно или в начале пометить ролик «Автономная репетиция · синтетический гость / FakeLLM + MockTransport». Не показывать токен или экран его ввода.

| Время | Кадр и действие |
|---|---|
| 00:00–00:15 | Главный экран уже подключённого демонстрационного номера, подзаголовок о персонализации |
| 00:15–00:45 | Заселение → план, затем профиль с реальными доступными предпочтениями |
| 00:45–01:15 | План вечер/ночь/утро, затем 6 устройств |
| 01:15–01:40 | «Сделай попрохладнее» → подтверждение |
| 01:40–02:08 | «Ещё немного» → подтверждение, затем ещё «Ещё немного» → подтверждение |
| 02:08–02:30 | «Поставь 35 градусов» → отказ и неизменное состояние |
| 02:30–03:00 | Открыть настройку света, установить допустимую яркость, подтвердить |
| 03:00–03:30 | Виртуальное время / ночь, согласованность с DND; закончить на главном экране |

Голос за кадром: «Номер готовится заранее по доступным предпочтениям. Житель может попросить изменить условия обычными словами. Безопасный исполнитель проверяет диапазоны и подтверждает результат у симулятора. Для официального финального гостя действуют ограничения read-only после закрытия /run».

OBS: 1920×1080, 30 FPS, H.264; сначала MKV, затем File → Remux recordings → MP4. Проверить захват браузера, курсор, микрофон и первые кадры. В Windows 10/11 Xbox Game Bar **Win+Alt+R** может записывать поддерживаемое окно приложения, итог обычно в `Видео\\Captures`. В совместимой Windows 11 можно пользоваться видеозаписью «Ножниц». Нельзя монтировать фиктивный успех. Итоговое имя: `SAIN-Smart-Room-Backup-Demo.mp4`.

Проверка: воспроизведение без интернета, звук, читаемость, ≤4 мин, нет личных данных/секретов, реальные подтверждения, понятное обозначение репетиции.
