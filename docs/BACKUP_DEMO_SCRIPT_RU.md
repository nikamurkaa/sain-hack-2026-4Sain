# SAIN Smart Room — сценарий резервной записи на 3–4 минуты

**Только синтетические данные.** Режим REHEARSAL обязан быть обозначен как автономная репетиция (FakeLLM + MockSimulator). Не выдавать за официальный final, не показывать токены.

| Время | Действия | Сопровождение |
|---|---|---|
| 0:00–0:15 | Готовый подключённый демонстрационный номер | «SAIN готовит номер заранее по доступным привычкам гостя». |
| 0:15–0:35 | «Заселиться», план и состояние комнаты | «Заселение не требует повторной анкеты». |
| 0:35–1:00 | Профиль, реальные доступные предпочтения | «Вот какие данные использованы; отсутствующие сведения не додумываются». |
| 1:00–1:20 | Вечер, ночь, утро в плане | «Из них сформирован сценарий отдыха». |
| 1:20–1:40 | Шесть устройств, температура до изменения | «Состояние поступает от симулятора». |
| 1:40–2:00 | Напечатать «Сделай попрохладнее» и дождаться подтверждения | «Ассистент понимает естественные просьбы». |
| 2:00–2:20 | «Ещё немного», потом ещё «Ещё немного»; показать три последовательных снижения | «Продолжение сохраняет контекст». |
| 2:20–2:40 | «Поставь 35 градусов»; показать отказ без изменения состояния | «Недопустимое значение отклоняется». |
| 2:40–3:05 | Свет → 38 % → Сохранить → фактическое состояние | «Ручная настройка подтверждается симулятором». |
| 3:05–3:30 | Виртуальное время → Ночь; показать DND и время | «Можно просмотреть момент действия ночных правил». |
| 3:30–3:45 | Вернуться на главный экран, статичный финал | «Номер подстраивается к гостю, а не наоборот». |

Стартуйте запись **после** ввода синтетического токена. OBS: 1920×1080, 30 FPS, MKV/H.264, затем File → Remux to MP4. Подробная инструкция: `BACKUP_VIDEO_RECORDING_GUIDE_RU.md`. Альтернатива на совместимой Windows: Win+Alt+R в Game Bar. Проверьте воспроизведение MP4 без интернета и отсутствие секретов. Если сценарий не работает — не монтируйте фальшивый успех.
